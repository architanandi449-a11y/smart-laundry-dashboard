# Smart-laundry-dashboard
AI-Based Laundry Order Management System with real-time order tracking, billing, and dashboard analytics built using React, Node.js, and MongoDB.
#  Laundry Order Management System (AI-First)

---

## Setup Instructions

This project is a **static web-based laundry management UI**.

### Run Locally

1. Download or clone the repository
2. Open the project folder
3. Double-click on:

```bash
index.html
```

- OR right-click → **Open with Browser**

---

### Deploy (Vercel)

* Upload the project to GitHub
* Import into Vercel
* Ensure:

  * `index.html` is in root directory
* No build command required

## 🔹 Features Implemented

### Order Creation

* Add customer name and phone number
* Add multiple garments
* Quantity selection
* Automatic bill calculation

### Order Tracking

* Status Updation system:

 * RECEIVED
 * PROCESSING
 * READY
 * DELIVERED

### Order View

* Display all orders
* Clean UI layout
* Real-time updates (client-side)

### Dashboard (UI-Level)

 * Total orders (simulated)
 * Status indicators
 * Visual separation of data

### UI/UX

 * Modern **blue + black theme**
 * Responsive design
 * Clean card-based layout
 * Smooth interactions
